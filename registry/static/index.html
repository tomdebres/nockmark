The Logos AI-PoW puzzle (INT8 tiled matmul + recursive STARK certificate), verified the same way: every rate computed by this server from certificates it checked, of challenges it derived. Two statements share this board — dense, the single-tile benchmark, and canonical MoE, the block mainnet AI miners actually run — because MAC-equivalents is the unit consensus itself uses to compare work of different shapes. Labeled CPU reference until GPU kernels exist upstream.

Each mark in the second column is drawn from that run's challenge nonce — a fingerprint of the workload the machine actually proved. Hardware descriptors are self-reported; rates are not.

nock/day is an estimate (attempt-lottery model at current difficulty and emission), shown when this instance has economics configured.
